# Skyline Tycoon
A free offline idle tycoon game for desktop (keyboard + mouse). Build floors, hire staff, Rebrand for permanent Fame.

**Controls:** Space/click = tap · 1–0 = buy floors · B = buy amount · U = next upgrade · Q/E = switch staff · T = tabs · M = mute

**Saves** live in your browser (localStorage). Use Fame tab → Export/Import save code to back up or move devices.

## Host on GitHub Pages
1. Create a repo, upload every file in this folder (index.html at the root).
2. Settings → Pages → Deploy from branch → `main` / root.
3. Open `https://<user>.github.io/<repo>/`. To ship an update, bump `C` in `sw.js` and push.
